# HoopTrust MVP User Flows

## Player flow

Sign up → create profile → upload video/link → submit stats → wait for verification → share profile → review contact requests.

## Recruiter flow

Apply for recruiter account → admin approval → search player profiles → save player → request contact → wait for approval.

## Admin flow

Review users → approve recruiters → review videos → verify stats → moderate profiles → monitor contact requests.

## Stat verification flow

Submitted stat line starts as `pending`. Admin compares it with video evidence, coach sheet, tournament record, or AI partner output. Admin changes status to `verified`, `needs_correction`, or `rejected`. Verified stats receive a public badge on the player profile.
